# dsh-voice-ru — русские доработки для голосового режима DeepSeek Harness

Небольшой набор правок, которые делают разговорный режим удобным по-русски.
Сам плагин — чужой (`@goodandready/dsh-voice` и `dsh-tts`), поэтому здесь лежат
**не копии файлов, а патчи и инструкции**, как их наложить на свою установку.

## Что правится и зачем

| Правка | Зачем |
|---|---|
| [`patches/01-mute-ctrl-m.md`](patches/01-mute-ctrl-m.md) | Ctrl+M выключает микрофон, не выходя из режима; подпись «Микрофон выключен» в плашке |
| [`patches/02-one-engine.md`](patches/02-one-engine.md) | один движок на страницу и защита от повторной отправки одной фразы |
| [`patches/03-device-change.md`](patches/03-device-change.md) | микрофон сам переподключается после смены звуковых устройств (например, после удалённого стола) |
| [`patches/04-barge-thresholds.md`](patches/04-barge-thresholds.md) | пороги перебивания: как и почему они подняты |
| [`patches/05-approval-voice.md`](patches/05-approval-voice.md) | фраза «Требуется разрешение» вслух, с русскими названиями инструментов |
| [`config/cordis-example.yml`](config/cordis-example.yml) | пример настроек профиля, который у нас работает |
| [`patches/06-end-of-utterance.md`](patches/06-end-of-utterance.md) | длинные фразы не обрываются на паузе (4,2 с тишины, досрочный конец — 1,6 с) |
| [`patches/07-level-hysteresis.md`](patches/07-level-hysteresis.md) | одиночный щелчок не считается речью; шумоподавление и автогромкость микрофона |
| [`patches/08-pronunciation.md`](patches/08-pronunciation.md) | ударения в озвучке: словарь `pronunciation` в профиле |

## Что ещё лежит в репозитории

- [`server/gigaam-server.mjs`](server/gigaam-server.mjs) — наш сервер
  распознавания GigaAM: обёртка над `sherpa-onnx-node`, сам ставит знаки
  препинания, исправляет «почти правильные» слова по частотному словарю и
  меняет точку на вопрос, когда фраза звучит как вопрос. Инструкция —
  [`server/README.md`](server/README.md). Веса модели в репозиторий не входят.
- [`tools/edge-warm-server.py`](tools/edge-warm-server.py) — тёплый воркер
  озвучки на edge-tts: один процесс вместо запуска CLI на каждую фразу,
  экономит около двух секунд на реплику. Работает по HTTP на localhost:
  `POST /tts {"text": "..."}` → mp3.

**Главная осторожность:** процессы, запущенные из сессии помощника, гаснут
вместе с ней. Сервер распознавания и воркер озвучки надо запускать
автозагрузкой (`.vbs` в папке Startup), а не из команды.

## Как накладывать

Каждый патч — отдельный файл с описанием: что заменить на что и в каком файле.
Пути указаны от корня профиля DSH:

```
C:\Users\<user>\.dsh\profiles\desktop\node_modules\@goodandready\dsh-voice\lib\client.js
```

После правки — перезапуск приложения (плагин читается при старте, обновление
страницы не помогает).

**Важно:** перед правкой сделайте копию файла. Обновление плагина затрёт правки —
после каждого обновления их надо накладывать заново.

## Настройки профиля

В `config/cordis.patch.yml` лежат фрагменты, которые у нас работают:

- `announceApproval: true` и `approvalText: 'Требуется разрешение'`;
- `autoSendMs: 300` (отправка почти сразу после отпускания клавиши «рации»);
- `hotkey: ''` — «рация» отключена: в разговорном режиме она мешает;
- `speechRms` / `minSubmitRms` — пороги, при которых шум не уходит сообщением.
