# Патч 4. Пороги перебивания: меньше ложных срабатываний

**Файл:** `lib/client.js` плагина разговорного режима, блок `TUNE`.

## Проблема

Перебивание срабатывало само: колонки играли ответ, микрофон ловил его
и «слышал» громкую речь. Разговор обрывался на полуслове без причины.

## Что изменено

```js
bargeStartThr: 0.12,    // было 0.09
bargeHoldThr: 0.09,     // было 0.07
bargeWindowHits: 8,     // было 7
```

Перебивание теперь засчитывается только на более громком и более
длительном звуке. Настоящее «стоп, подожди» срабатывает, а всплески от
динамиков — нет.

## Как подбирать

- Перебивания не слышат вас — уменьшайте `bargeStartThr` на 0.01.
- Перебивания срабатывают сами — увеличивайте.

## Если есть эхоподавление

Проверьте, что при открытии микрофона запрошено `echoCancellation: true`
в `getUserMedia`. Часть устройств его игнорирует — в журнале тогда будет
`mic settings: aec=false`.
