# Патч 5. «Требуется разрешение» вслух и по-русски

**Файлы:** плагин озвучки `@goodandready/dsh-tts` (`lib/index.js`) и профиль
DSH (`cordis.patch.yml`).

## Зачем

Когда ассистент просит разрешение на команду, он показывает диалог. В
разговоре голосом это неудобно: приходится смотреть на экран и догадываться,
что от вас хотят. Простая фраза вслух решает.

## 1. Профиль

```yaml
- id: dsh-tts
  config:
    announceApproval: true
    approvalText: 'Требуется разрешение'
```

Плагин допишет к фразе имя инструмента: «Требуется разрешение: pwsh».

## 2. Русские названия инструментов (патч плагина)

В `lib/index.js`, рядом с обработчиком `approval/asked`:

```js
const TOOL_NAMES_RU = {
  pwsh: 'терминал',
  read: 'чтение файлов',
  write: 'запись файлов',
  edit: 'правка файлов',
  glob: 'поиск файлов',
  grep: 'поиск по файлам',
  web_search: 'поиск в интернете',
  web_fetch: 'загрузка страницы',
  subagent: 'помощник',
  present: 'файлы',
};

function toolNameRu(name) {
  if (!name) return '';
  return TOOL_NAMES_RU[name] || 'действие';
}
```

И в двух местах, где собирается фраза:

```js
announce(sid, cfg.approvalText + (tool ? ': ' + toolNameRu(tool) : ''), cfg, gen)
```

## Важно

Правка живёт **внутри плагина**. При его обновлении файл заменяется, и таблицу
надо добавить заново. Держите этот файл под рукой.

## Что мы пробовали и отказались

- **«Рация» на F9 и на Ctrl+Space.** В разговорном режиме она мешает: либо
  не срабатывает, либо залипает, либо пропадает кнопка микрофона. Итог:
  `hotkey: ''` — «рация» отключена, остаётся Ctrl+M и кнопка микрофона.
- **Разрешения голосом.** Отказались сознательно: ошибка распознавания может
  открыть доступ к чему угодно. Только мышкой.
