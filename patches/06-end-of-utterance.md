# Патч 6. Длинные фразы не обрываются на паузе

**Файл:** `lib/client.js` плагина разговорного режима, блок `TUNE`.

## Проблема

Человек говорит спокойно, делает паузу «подумать» — и реплика уходит
обрезанной на половине. Причина была в том, что концом реплики считалась
любая тишина в 2,5 секунды, а промежуточное распознавание всегда добавляет
точку, поэтому «фраза закончена» срабатывало почти на каждой паузе.

## Что изменено

```js
silenceMs: 4200,        // было 2500 и 3500: жёсткий конец только по большой тишине
earlyEndMs: 1600,       // «законченная» расшифровка отправляется не раньше 1,6 с тишины
peekEndsTurn: false,    // промежуточное распознавание само реплику не заканчивает
maxUtteranceMs: 180000, // три минуты на одну реплику
minWordsToTrust: 8,     // короче восьми слов — не повод заканчивать досрочно
silenceSoftMs: 800,     // «звучит законченно» — только подсказка, запись идёт дальше
```

## Что это даёт

Законченная мысль уходит примерно через 1,6 секунды тишины, а задумчивая
пауза посреди фразы реплику больше не режет. Если человек молчит дольше
4,2 секунды — это и есть конец.

## Как подбирать

- Реплика всё ещё обрывается — увеличивайте `silenceMs` и `earlyEndMs`.
- Ответ приходит с заметной задержкой после того, как вы закончили — уменьшайте
  `earlyEndMs` (но не ниже 1200, иначе паузы начнут резать фразу).
