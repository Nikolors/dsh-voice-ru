# Патч 8. Ударения в озвучке: словарь для русской речи

**Файл:** профиль DSH, `cordis.patch.yml`, раздел `dsh-tts` → `pronunciation`.
Правка не в плагине, а в настройках профиля, поэтому перезапуск приложения
нужен, но обновление плагина её не затирает.

## Проблема

Нейроголос угадывает ударение сам и иногда ошибается: «а́ватар» вместо
«авата́р». Знак ударения (акут) не помогал — голос ставил два ударения
подряд, и слово звучало ещё хуже.

## Решение

Ударение задаётся **заглавной буквой** на ударном гласном. Голос читает
такое слово как слово с ударением на этой букве, второго ударения не
появляется.

```yaml
pronunciation:
  - { from: 'аватар',  to: 'аватАр',  whole: true, lang: 'ru' }
  - { from: 'аватара', to: 'аватАра', whole: true, lang: 'ru' }
  - { from: 'озвучка', to: 'озвУчка', whole: true, lang: 'ru' }
  - { from: 'озвучку', to: 'озвУчку', whole: true, lang: 'ru' }
```

`whole: true` означает «целое слово», чтобы правило не трогало куски других
слов. `lang: 'ru'` — чтобы замены не применялись к английскому тексту.

## Как пополнять

Услышали неверное ударение — добавьте пару строк на все падежи, которые
встречаются в речи («рынок», «рынка», «рынку»…). У нас в словаре 60+ таких
правил: техника, названия сайтов, имена.

## Отдельно: произношение терминов

Для латиницы (Cloudflare, WireGuard, YouTube) проще не ударение, а замена
написания на русское чтение в том же разделе профиля — тогда голос не
пытается читать по-английски. Мы так же правим «DSH» → «ди-эс-эйч».
